# InventoryInvoiceApp

InventoryInvoiceApp is an inventory and invoice management system developed using ASP.NET Core MVC, C#, Entity Framework Core, and SQL Server.

## Features

* User registration and login
* Role-based access control
* Inventory and material management
* Invoice creation and management
* Add, edit, view, and delete records
* Input validation
* Secure database integration

## Technologies

* ASP.NET Core MVC
* C#
* Entity Framework Core
* SQL Server
* ASP.NET Core Identity
* HTML, CSS, JavaScript, and Bootstrap

## Purpose

This project was created to practise web development, database management, authentication, authorization, and secure application deployment using IIS.
